# Public presentation assets

Original vector artwork for KairoTensor's repository landing page. The diagrams
are conceptual illustrations, not measurements, causal proofs, or evidence of
model execution. The lifecycle is deliberately simplified; linked contract pages
remain the authority for reserve/claim/settlement and reuse behavior.

| Token | Color | Use |
| --- | --- | --- |
| Midnight | `#0B1023` | Diagram background |
| Paper | `#F4F6FC` | Main lettering |
| Mist | `#C1CBE0` | Supporting lettering |
| Cyan | `#66E4EA` | Evidence and eligibility |
| Violet | `#C4AFFB` | Captured attempts and change |
| Amber | `#F5CE7A` | Accounting |
| Print teal | `#12566A` | Paper heading accent on white |

`hero.svg` and `evidence-lifecycle.svg` are editable sources with embedded titles
and descriptions, explicit view boxes, no scripts, no remote assets and no font
fetches. Labels accompany all color distinctions. README alternative text and
surrounding prose carry the same information for readers who cannot see the art.
GitHub embeds the SVGs as images; both include their own dark background for
consistent contrast in light and dark themes. DejaVu Sans/Arial are fallback fonts,
not bundled dependencies. No photographic or generated-image source is used.

The report retains its academic template. Its restrained teal headings and pale
blue table headers share this palette without importing the dark cover artwork.
